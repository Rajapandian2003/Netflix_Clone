🔥 Netflix India Clone - (DEVELOPED FOR ONLY PC VIEW...!)
This is a responsive Netflix India landing page clone built using HTML, CSS, and JavaScript. The project replicates the look and feel of Netflix’s official homepage with custom styles and interactive sign-in navigation.

📁 Project Structure
index.html – The main homepage of Netflix with promotional sections, email input, and FAQs.
signin.html – A styled sign-in interface with basic input fields.
style.css – All the custom styling for layout, responsiveness, hover effects, buttons, and design aesthetics.
script.js – Handles redirection between pages using simple JavaScript navigation functions.

🌟 Features
🎨 Clean and responsive UI
🎥 Modern Netflix-style sections for TV, mobile, kids, and downloads
🌐 Language selector UI
🔐 Basic Sign-In page design
📱 Mobile responsiveness included (commented in CSS)
📦 Organized and scalable codebase
